# PR18 regional and dungeon scenery

Fifteen source-authored CC0 GLBs from the immutable Papyszoo CC0 public-domain catalog revision `77343cac874f06b73d16ad0063339df7c9ca254c` (Kenney, KayKit, Quaternius and The Base Mesh). Original bytes, download sizes, SHA256 values and exact paths are in `manifest.json`; the catalog's CC0 license is included.

Reimport: `node scripts/import-pr18-world.mjs`. Runtime uses these files as immutable templates, cloning per-scene render geometry/materials and disposing owned instances at unload. No character, animal or prop is generated from primitive shapes.
